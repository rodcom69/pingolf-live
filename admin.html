Events

Machine down? Close the hole
Close temporarily = machine down for now: nobody can enter a score there, par stays the same, and scores already in still count. Tap Reopen when it works. Close permanently = it won't come back: the hole is dropped for everyone, its scores stop counting, and par drops by 3. Closed permanently by mistake? Tap Undo permanent close; every score comes back.

Location admin PINs
Each location has its own admin page and PIN. With it they can start competitions, open/finish their events, close holes, and fix, void or add scores, only at their own location. Type a PIN (4–8 digits) and tap Set. PINs you set here are shown on this computer.
